# FinAl
Official repository of "FinAl: Fine-grained Alignment for Detail-Preserving Medical Vision-Language Pretraining (NeurIPS, 2026)"

FinAl uses similarity rankings between radiology reports to provide soft supervision for fine-grained medical image–text representation learning.

Code and pretrained checkpoints will be released soon.
